## 多账号使用说明

每日签到任务现在支持保存多个 B 站账号。使用方法：

1. 保持脚本的 Cookie 获取重写开启。
2. 登录第一个账号并触发一次 Cookie 获取，收到成功通知后切换到下一个账号。
3. 对每个需要签到的账号重复上述步骤；脚本会按 `DedeUserID` 自动新增或更新对应账号的 Cookie。
4. 到定时任务执行时，脚本会读取已保存的账号列表并逐个完成每日任务。

> BoxJS 中的投币次数、充电用户等设置仍作为所有账号的通用设置生效。
